Installation Guide

Chrome

1

Download the .zip file

Click the Chrome download button for the extension you want.

2

Extract the zip

Right-click the .zip → Extract All. Remember where you saved it.

3

Open Chrome Extensions

Go to chrome://extensions. Enable Developer mode (top-right toggle).

4

Load the extension

Click Load unpacked → select the extracted folder. Done!

Firefox

1

Download the .xpi file

Click the Firefox button. Firefox may ask to install directly — click Add.

2

Allow the install

If prompted, click Install Anyway or set xpinstall.signatures.required = false in about:config.
